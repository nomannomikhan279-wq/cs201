LEC 01

What is Programming?

Program (Definition)
A precise sequence of steps to solve a particular problem. A program tells a computer exactly what to do, in exactly the right order — nothing more, nothing less.
Why Programming is Important
Develops analytical thinking, critical reading, and creative synthesis. Programming is not just a vocational skill — it teaches problem-solving applicable to all professions.
Key Programming Skills
Attention to Detail Think Reusability Good User Interface Comment Code Liberally

Computers are stupid — they do exactly what you say. You cannot be vague or assume the computer will "figure it out."
Program Design Recipe
1. Analyze — Read and understand the problem statement carefully.
2. Express — Write its essence with examples and abstract ideas.
3. Formulate — Write precise pseudocode or a flowchart.
4. Evaluate — Test, check results, and revise until correct.
LEC 02

Software Categories & History of C

System Software
Controls computer hardware. Sub-categories:
Operating System — Manages CPU, memory, disk, peripherals (e.g. Windows, Linux).
Device Drivers — Software that lets the OS communicate with specific hardware (e.g. sound card driver).
Utilities — Specific tools like disk defragmenter or compression utility.
Compilers & Interpreters — Also classified as system software.
Application Software
Programs designed for end users to perform specific real-world tasks.
Example: MS Word (word processing), a payroll system, GPS navigation app.
History of C Language
Developed by Dennis Ritchie at Bell Labs ~1972, built on BCPL and B languages.
C became the development language of the UNIX operating system.
Standardized as ANSI C in 1989 (also known as C89).
Development Tools (The Toolchain)
Editor — Write source code as plain text (.c or .cpp file).
Compiler — Translates whole program to machine code; stops at first syntax error.
Interpreter — Translates and runs line-by-line; shows errors as it goes but is slower.
Linker — Combines object code with library functions into one executable.
Loader — Loads the executable from disk into RAM and starts execution.
Debugger — Lets you pause, inspect variables, and trace logical errors at runtime.
LEC 03

First C Program, Variables & Data Types

First C Program
#include <iostream.h>   // include standard I/O library

main()
{
    cout << "Welcome to Virtual University";  // print to screen
}
#include — preprocessor directive to include a library file.
main() — every C program starts executing from main().
cout << — sends data to the screen (output stream).
; — every statement must end with a semicolon.
Variables
Named memory locations that store data. Every variable has a name, type, size, and value. Names must start with a letter (avoid leading underscore — reserved by libraries).
Assignment Operator ( = )
x = 5 means "store the value 5 in memory location x." This is NOT algebraic equality. Left side must always be a single variable name.
int x;
x = 10;           // stores 10 in x
x = x + 1;        // x becomes 11  (valid in C, not algebra)
x = x * 2;        // x becomes 22
Data Types
int Whole numbers — 4 bytes — range: ~−2 billion to +2 billion
short Small whole numbers — 2 bytes — range: −32768 to 32767
long Very large whole numbers — 4+ bytes
float Decimal numbers — 4 bytes — e.g. 3.14f
double High-precision decimals — 8 bytes — e.g. 3.1415926
char Single character — 1 byte — e.g. 'A', 'z', '5' 
int    age    = 20;
float  gpa    = 3.75;
double salary = 45000.99;
char   grade  = 'A';       // single quotes for char
Arithmetic Operators & Precedence
+ Addition   - Subtraction   * Multiplication   / Division   % Modulus (remainder)

Integer division truncates: 5 / 2 = 2 (not 2.5). Use float/double for decimal results.
Modulus: 5 % 2 = 1  |  23 % 5 = 3  |  Only works with integers.
Precedence: ( ) → *, /, % → +, −  (all left-to-right within same level) 
int result;
result = 10 + 10 * 5;     // = 60  (* first, then +)
result = (10 + 10) * 5;   // = 100 (parentheses force + first)
result = 7 % 3;            // = 1   (remainder of 7 / 3)
LEC 04

Expressions, cin & Practical Examples

cin — Standard Input
cin >> variableName reads user keyboard input and stores it in a variable. The program pauses and waits. Press Enter to confirm. Only ONE variable per >> token.
#include <iostream.h>
main()
{
    int age;
    cout << "Enter your age: ";
    cin  >> age;                  // waits for user to type and press Enter
    cout << "You are " << age << " years old.";
}
Writing Algebraic Expressions in C
C has no power operator. Use * repeatedly for powers. Use parentheses to make the order of evaluation explicit.
// Algebra: y = ax² + bx + c
y = a * x * x + b * x + c;

// Algebra: (b² - 4ac) / 2a
result = (b * b - 4 * a * c) / (2 * a);
// Without parentheses this would give the WRONG answer!
Extracting Digits Using % and /
number % 10 gives the last digit. number / 10 (integer division) removes the last digit. Repeat to extract all digits one by one.
int number = 7531, digit;

digit  = number % 10;   // digit = 1  (last digit)
number = number / 10;   // number = 753

digit  = number % 10;   // digit = 3
number = number / 10;   // number = 75

digit  = number % 10;   // digit = 5
number = number / 10;   // number = 7  (last digit remaining)
Average Age Program (Full Example)
#include <iostream.h>
main()
{
    int age1, age2, age3;
    int totalAge, averageAge;

    cout << "Enter age of student 1: "; cin >> age1;
    cout << "Enter age of student 2: "; cin >> age2;
    cout << "Enter age of student 3: "; cin >> age3;

    totalAge   = age1 + age2 + age3;
    averageAge = totalAge / 3;       // integer division truncates decimal

    cout << "Average age = " << averageAge;
}
LEC 05

Conditional Statements (if / if-else / Logical Operators)

if Statement
Executes a block only when the condition is true. Use { } braces to group multiple statements into one block.
if (condition)
{
    statement1;
    statement2;
}

// Example: check if student is older
if (AmerAge > AmaraAge)
{
    cout << "Amer is older than Amara";
}
Relational Operators
> Greater than   < Less than   == Equal to   != Not equal   >= Greater or equal   <= Less or equal

⚠️ == (comparison) is completely different from = (assignment). Writing if (x = 2) instead of if (x == 2) is a silent logical error! 
int x = 5, y = 10;

if (x == y)  cout << "equal";       // false
if (x != y)  cout << "not equal";   // true
if (x <  y)  cout << "x less";     // true
if-else Structure
Executes one block if true, a different block if false. The else covers ALL cases not matched by the if condition.
if (amount > 5000)
{
    discount = amount * (15.0 / 100);   // 15% discount
}
else
{
    discount = amount * (10.0 / 100);   // 10% discount
}
netPayable = amount - discount;
Logical Operators
&& (AND) — Both conditions must be true for the whole expression to be true.
|| (OR) — At least one condition must be true.
! (NOT) — Reverses the truth value of a condition (unary operator). 
// AND: both must be true
if (age > 18 && height > 6)
    cout << "Selected for basketball team";

// OR: at least one must be true
if (degree == 'B' || degree == 'M')
    cout << "Admitted to university";

// NOT: reverses the condition
if (!(age > 18))
    cout << "Age is 18 or below";
LEC 06

Repetition Structure – while Loop

while Loop
Repeats a block as long as a condition is true. Condition is tested before each iteration. May execute zero or more times.
while (condition)
{
    statement(s);
}

// Example: sum of first 1000 integers
int sum = 0, number = 1;

while (number <= 1000)
{
    sum    = sum + number;   // add current number to sum
    number = number + 1;    // move to next integer
}
// Result: sum = 500500
Overflow Condition
Occurs when a computed value exceeds the maximum a data type can hold. For int (4 bytes) the max is ~2.1 billion. Overflow causes either a runtime error or a silently wrong (wrapped) value. Use long or double for large numbers.
Infinite Loop
A loop whose condition never becomes false. Always happens when the loop variable is never updated inside the body. Must be avoided.
// WRONG — infinite loop: number never changes
while (number <= 1000)
{
    sum = sum + number;
    // number = number + 1;   <-- MISSING! loop runs forever
}
Factorial Using while
int number, factorial = 1;
cout << "Enter number: ";
cin  >> number;

while (number > 1)
{
    factorial = factorial * number;
    number    = number - 1;
}
cout << "Factorial = " << factorial;
LEC 07

do-while Loop, for Loop & Increment/Decrement Operators

do-while Loop
Condition is checked AFTER the body executes. Guarantees the body runs at least once. Used for menus, input validation, guessing games.
do
{
    statement(s);
} while (condition);   // note semicolon here!

// Example: guess a character, 5 tries allowed
int  tryNum = 0;
char c;
do
{
    cout << "Guess a character (a-z): ";
    cin  >> c;
    if (c == 'z')
        cout << "Correct!";
    else
        tryNum++;
} while (tryNum <= 5 && c != 'z');
for Loop
Combines initialization, condition, and increment in one compact line. Best when the number of iterations is known in advance.
for (initialization; condition; increment)
{
    statement(s);
}

// Example: print multiplication table of 7
int counter;
for (counter = 1; counter <= 10; counter++)
{
    cout << "7 x " << counter << " = " << 7 * counter << "\n";
}
Increment & Decrement Operators
++ (increment) — adds 1 to a variable.
-- (decrement) — subtracts 1 from a variable.
Pre (++x) — increment FIRST, then use the new value in the expression.
Post (x++) — use the current value in the expression, THEN increment. 
int j = 5, x;

x = ++j;   // pre-increment:  j becomes 6 first, then x = 6
x = j++;   // post-increment: x = 6 first, then j becomes 7

// Compound assignment operators (shorthand):
x += 4;    // same as x = x + 4
x -= 3;    // same as x = x - 3
x *= 2;    // same as x = x * 2
x /= 2;    // same as x = x / 2
x %= 3;    // same as x = x % 3
Sum of Squares Using for Loop
// Sum = 1² + 2² + 3² + ... + n²
int i, n, sum = 0;
cout << "Enter n: ";
cin  >> n;

for (i = 1; i <= n; i++)
{
    sum += i * i;   // sum = sum + i²
}
cout << "Sum of squares = " << sum;
LEC 08

switch, break, continue & Structured Programming

switch Statement
A multi-way decision construct. Evaluates an integer or char variable and jumps directly to the matching case. More efficient than many chained if-else statements. Without break, execution "falls through" to the next case — a common logical error!
switch (grade)
{
    case 'A':
    case 'a':                        // both A and a share same action
        cout << "Excellent";
        break;                       // exit switch — REQUIRED!
    case 'B':
    case 'b':
        cout << "Very Good";
        break;
    case 'C':
    case 'c':
        cout << "Good";
        break;
    default:                         // no case matched
        cout << "Invalid grade";
}
break Statement
Immediately exits the innermost loop or switch. Used to terminate a loop early when a desired condition is met.
for (i = 0; i < 100; i++)
{
    if (a[i] == target)
    {
        found = 1;
        break;           // stop searching as soon as target is found
    }
}
continue Statement
Skips the rest of the current iteration and jumps to the next iteration. In a for loop, the increment expression is still executed before the next check.
// Print only odd numbers from 1 to 10
for (i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
        continue;        // skip even numbers
    cout << i << " ";
}
// Output: 1 3 5 7 9
Structured Programming Rules
Any program can be written using only three constructs: sequence, decisions, and loops.
Every module should have single entry and single exit.
Never use goto — it creates unreadable "spaghetti code".
Minimize use of break and continue inside loops.
LEC 09

Functions

What is a Function?
A named, reusable block of code that performs a specific task. Receives input (arguments), processes, and returns a result. Enables top-down design and code reuse.
Function Structure: Declaration & Definition
// Declaration (prototype) — tells compiler about the function
int square(int);               // return type, name, param types only

// Definition — actual code with parameter names
int square(int number)
{
    int result = number * number;
    return result;              // return exits function and sends back the value
}
Calling a Function
#include <iostream.h>
int square(int);             // prototype must appear before use

main()
{
    int num = 5, result;
    result = square(num);     // function call — passes copy of num
    cout << "Square = " << result;   // prints 25
}

int square(int number)       // definition
{
    return number * number;
}
Call by Value (Default)
A copy of the argument is passed to the function. The original variable in the calling program is NOT changed. Safe — no side effects on caller's data.
void Functions (No Return Value)
void printLine()          // void = no return value
{
    cout << "--------------------\n";
}                           // no return statement needed
Recursive Function
A function that calls itself. Must have a base case to stop recursion. Elegant but uses extra memory for each call on the stack.
long factorial(long n)
{
    if (n <= 1)
        return 1;                       // base case: stop recursion
    return n * factorial(n - 1);       // recursive case
}
// factorial(4) = 4 * factorial(3) = 4 * 3 * 2 * 1 = 24
LEC 10

Header Files, Scope of Identifiers & Call by Reference

Header Files
A text file (.h extension) containing function prototypes and constant definitions. Included with #include. Avoids rewriting declarations in every file.
#include <iostream.h>    // system header (angle brackets)
#include "myFunctions.h" // user-made header (double quotes)
#define — Named Constants
Associates a name with a value. Before compilation, every occurrence of the name is replaced by the value. It is NOT a variable — you cannot assign to it.
#define PI   3.1415926
#define MAX  100

// Usage in code:
circumference = 2 * PI * radius;   // compiler replaces PI with 3.1415926
Scope of Variables
Block scope — Declared inside { }; visible only within that block.
Function scope — Declared inside a function; not visible in other functions.
Global scope — Declared outside all functions; visible everywhere in the file. Use sparingly — global variables can be accidentally changed by any function. 
int globalVar = 10;          // global — visible in all functions below

void funcA()
{
    int localVar = 5;         // local — only visible inside funcA
    globalVar = 20;           // OK: accessing global variable
}

void funcB()
{
    // localVar not accessible here — it's local to funcA
    globalVar = 30;           // OK: global still accessible
}
Call by Reference (using Pointers)
Passes the memory address (&) of a variable. The called function modifies the original variable directly. Used when a function must change the caller's data.
void doubleIt(int *n)      // receives address of n
{
    *n = *n * 2;            // modifies the ORIGINAL variable
}

main()
{
    int x = 5;
    doubleIt(&x);            // pass address of x
    cout << x;               // prints 10
}
LEC 11

Arrays

What is an Array?
A data structure storing a fixed collection of same-type elements in contiguous memory. Accessed by an index (subscript). Useful when many values of the same kind are needed (e.g. 100 student ages).
Declaration, Indexing & Access
Index starts at 0, ends at size−1. Declaration reserves memory; each element is used like a simple variable.
int age[5];          // declares 5 integers: age[0]..age[4]

age[0] = 20;         // assign first element
age[4] = 25;         // assign last element
cout << age[2];       // print third element
Initialization
int age[5] = {12, 13, 16, 13, 14};   // explicit values
int age[]  = {10, 20, 30};             // compiler sets size = 3
int age[5] = {0};                       // all elements set to 0

// Using a loop (best for large arrays):
for (i = 0; i < 5; i++)
    age[i] = 0;
Processing Arrays with Loops
// Input ages, then compute average
const int SIZE = 10;
int age[SIZE], i, total = 0;

for (i = 0; i < SIZE; i++)
{
    cout << "Enter age " << (i + 1) << ": ";
    cin  >> age[i];
}
for (i = 0; i < SIZE; i++)
    total += age[i];

cout << "Average = " << total / SIZE;
Linear Search
int target, found = 0, pos = -1;
cout << "Enter number to find: "; cin >> target;

for (i = 0; i < SIZE; i++)
{
    if (a[i] == target)
    {
        found = 1; pos = i;
        break;                // stop once found
    }
}
if (found) cout << "Found at index " << pos;
else       cout << "Not found";
const for Array Size (Best Practice)
const int ARRAY_SIZE = 100;
int scores[ARRAY_SIZE];

for (i = 0; i < ARRAY_SIZE; i++)
    scores[i] = 0;
// If size changes, update ONLY the const declaration — code stays valid
LEC 12

Character Arrays, Sorting, Searching & 2D Arrays

Character Arrays (Strings)
A string in C is a char array terminated by '\0' (null character). The null marks the end of the string. Array size must be at least (number of characters + 1).
char name[100];                     // can hold up to 99 chars + '\0'
cin  >> name;                        // reads one word (stops at space)
cout << name;                        // prints until '\0' is reached

// Initialization:
char city[] = "Lahore";             // compiler appends '\0' automatically
// Equivalent to: {'L','a','h','o','r','e','\0'}
Arrays Passed to Functions = Automatic Call by Reference
The array name holds the address of its first element. Passing an array to a function passes this address, so the function modifies the original array — NOT a copy.
void fillArray(int arr[], int size)  // receives address of arr[0]
{
    for (int i = 0; i < size; i++)
        arr[i] = i * 10;            // changes the ORIGINAL array
}

main()
{
    int nums[5];
    fillArray(nums, 5);
    cout << nums[2];               // prints 20 — original was changed
}
Swapping Two Values
int a = 5, b = 10, temp;
temp = a;    // save a
a    = b;    // overwrite a with b
b    = temp; // give saved value to b
// Now a = 10, b = 5
Binary Search (on Sorted Arrays)
Divides the search space in half each step. Works only on sorted arrays. Maximum iterations = log₂(n). For 1000 elements: ≤ 10 comparisons vs 1000 for linear search.
int low = 0, high = SIZE - 1, mid, target;
cin >> target;

while (low <= high)
{
    mid = (low + high) / 2;
    if (a[mid] == target) { cout << "Found at " << mid; break; }
    else if (target > a[mid]) low  = mid + 1; // search right half
    else                       high = mid - 1; // search left half
}
2D Arrays (Matrices)
int matrix[2][3];             // 2 rows, 3 columns
int row, col;

// Fill with nested loops:
for (row = 0; row < 2; row++)
    for (col = 0; col < 3; col++)
    {
        cout << "Enter [" << row << "][" << col << "]:";
        cin  >> matrix[row][col];
    }

matrix[1][2] = 99;              // access row 1, column 2
LEC 13

Array Manipulation & Real-World Problem Design

Flipping a Matrix (Reverse Row Order)
Display rows bottom-to-top by running the outer loop from maxRows−1 down to 0. The actual array data is not changed — only the display order.
// Display matrix with rows in reverse order
for (row = maxRows - 1; row >= 0; row--)
{
    for (col = 0; col < maxCols; col++)
        cout << a[row][col] << "\t";
    cout << "\n";
}
Transpose of a Square Matrix
Swap element [i][j] with [j][i]. To avoid double-swapping, iterate only over the upper triangle: start inner loop at col = row (not 0).
int temp;
for (row = 0; row < SIZE; row++)
{
    for (col = row; col < SIZE; col++)   // col starts at row, NOT 0
    {
        temp        = a[row][col];
        a[row][col] = a[col][row];
        a[col][row] = temp;
    }
}
Design Recipe for Real-World Problems
1. Precise problem statement — state exactly what must be solved.
2. Identify inputs, outputs, constants — what data is needed?
3. Break into functions — getInput(), calcNetSal(), findUnluckies(), printResults().
4. Code and test each function separately before integrating.
2D Array for Salary Data
double sal[100][2];    // sal[i][0] = gross salary
                        // sal[i][1] = net salary after tax

// Calculate net salary based on tax brackets:
for (int i = 0; i < numEmps; i++)
{
    if (sal[i][0] <= 5000)
        sal[i][1] = sal[i][0];                    // 0% tax
    else if (sal[i][0] <= 10000)
        sal[i][1] = sal[i][0] - sal[i][0] * 0.05;  // 5% tax
    else
        sal[i][1] = sal[i][0] - sal[i][0] * 0.10;  // 10% tax
}
LEC 14

Pointers

What is a Pointer?
A variable that stores a memory address (not a value). Provides indirect access to data — the pointer "points to" the memory location where the data lives.
Declaring Pointers
Syntax: datatype *pointerName; — The * is attached to the variable name, not the type. Each pointer in a declaration needs its own *.
int    *ptr;     // ptr is a pointer to int
double *dptr;    // dptr is a pointer to double
char   *cptr;    // cptr is a pointer to char

int *p1, *p2, *p3;  // three int pointers in one line
int *p, x, arr[5];  // p = pointer, x = int, arr = array
Address Operator (&) & Dereference Operator (*)
int x = 10;
int *ptr;

ptr = &x;         // &x = address of x; now ptr points to x

cout << ptr;      // prints the memory address (e.g. 0x22ff7c)
cout << *ptr;     // dereference: prints 10 (value stored at that address)

(*ptr)++;          // increment the VALUE at the address: x becomes 11
cout << x;        // prints 11 — original variable was changed!
NULL Pointer (Safe Initialization)
int *ptr = NULL;    // points to nothing — safe initial state
// OR:
int *ptr = 0;       // 0 is not a valid address, means "no target"

// Always assign a valid address before dereferencing:
ptr = &x;
*ptr = 50;           // now safe — ptr points to x
swap() Using Pointers (Call by Reference)
void swap(int *x, int *y)   // receives addresses of two variables
{
    int temp = *x;            // save value at address x
    *x = *y;                  // put value of y into x's location
    *y = temp;                // put saved value into y's location
}

main()
{
    int a = 5, b = 10;
    swap(&a, &b);             // pass addresses
    cout << a << " " << b;    // prints: 10 5
}
LEC 15

Pointer Arithmetic & Pointers with Arrays/Strings

Array Name = Constant Pointer
The name of an array IS a constant pointer to the address of its first element. It cannot be reassigned. A normal pointer variable can be assigned the array's address and then moved freely.
int y[10];
int *yptr;

yptr = y;            // yptr now points to y[0]
// y = yptr;  ERROR! array name is a constant pointer — cannot reassign
Pointer Arithmetic — Increment / Decrement
When a pointer is incremented, it advances by the size of its data type in bytes, not by 1. For an int pointer (4 bytes): ptr++ adds 4 to the address.
int y[5] = {10, 20, 30, 40, 50};
int *p = y;           // p points to y[0]

cout << *p;           // 10
p++;                  // p now points to y[1] (address +4 bytes)
cout << *p;           // 20

// Three equivalent ways to access y[5]'s element at index 3:
cout << y[3];          // array indexing
cout << *(y + 3);     // pointer arithmetic on array name
cout << p[2];          // indexing a pointer variable
Pointer Subtraction
Subtracting two pointers of the same type gives how many elements apart they are. Addition of two pointers is NOT allowed.
int arr[10];
int *p1 = &arr[0];   // points to element 0
int *p2 = &arr[3];   // points to element 3

cout << (p2 - p1);   // prints 3 (three elements apart)
Traversing a String with a Pointer
char str[] = "Hello";
char *sptr = str;          // points to 'H'

while (*sptr != '\0')      // loop until null terminator
{
    cout << *sptr;          // print current character
    sptr++;                  // advance to next character
}
// Output: Hello
const with Pointers
const int *ptr = &x;  // pointer to const int
                        // value at address cannot change via ptr
                        // but ptr itself can point elsewhere

int *const ptr = &x;  // const pointer to int
                        // ptr always points to x (cannot reassign ptr)
                        // but value at x can change
LEC 16

Pointers to Pointers, Arrays of Pointers & Command-line Arguments

Pointer to Pointer (Double Indirection)
A pointer that stores the address of another pointer. Written as **ptr. Used for 2D arrays, arrays of strings, and dynamic allocation.
int   x   = 42;
int  *p   = &x;    // p  holds address of x
int **pp  = &p;    // pp holds address of p

cout << **pp;      // 42 — double dereference: pp->p->x

// Accessing 2D array element using pointer notation:
int multi[3][3];
// multi[2][1] is the same as:
*(*(multi + 2) + 1)    // row 2, col 1
Array of Pointers — Variable-Length Strings
Instead of a fixed 2D char array (wastes space), use an array of char pointers. Each pointer points to a string of its own length — no wasted memory.
// Fixed 2D array wastes space (each row is 20 chars wide):
char names[3][20] = {"Ali", "Jehangir", "Muhammad Usman"};

// Array of pointers — uses only what each string needs:
char *names[] = {"Ali", "Jehangir", "Muhammad Usman"};
// names[0] -> 4 bytes, names[1] -> 9 bytes, names[2] -> 15 bytes

cout << names[1];   // prints "Jehangir"
Command-line Arguments (argc & argv)
argc — integer count of command-line arguments (program name counts as #1).
argv — array of strings (char**); each argument is a character string.
void main(int argc, char **argv)
{
    // Running:  myProgram.exe  10  display
    // argc = 3
    // argv[0] = "myProgram.exe"
    // argv[1] = "10"
    // argv[2] = "display"

    if (argc < 2)
    {
        cout << "Please provide arguments";
        return;
    }
    int count = atoi(argv[1]);    // convert "10" string to integer 10
    cout << "Count = " << count;
}
2D Array Name Pointer Behaviour
Adding 1 to a 2D array name skips an entire row (all columns), because the compiler knows the row width = columns × element size.
char grid[5][10];

// grid       points to row 0 (address of grid[0][0])
// grid + 1   points to row 1 (jumps 10 bytes for 10 chars)
// grid + 2   points to row 2
// *grid      is address of first element of row 0
// **grid     is the value of grid[0][0]
LEC 17

String Handling — <ctype.h>, <string.h>, <stdlib.h>

ASCII Codes & Characters
Every character is stored internally as a number (ASCII code). 'A'–'Z' = 65–90, 'a'–'z' = 97–122, '0'–'9' = 48–57. C is case-sensitive: 'A' ≠ 'a'.
char c = 'A';
int  n = c;           // n = 65  (ASCII value of 'A')
cout << (c + 1);      // prints 66 (numeric) — NOT 'B'
cout << (char)(c + 1); // prints 'B' (cast back to char)
Character Test Functions — <ctype.h>
All return non-zero (true) or 0 (false). Include #include <ctype.h>.
#include <ctype.h>

char c = 'G';
isdigit(c)   // 0 (false)  — is it a digit 0-9?
isalpha(c)   // true       — is it a letter a-z or A-Z?
isupper(c)   // true       — is it uppercase?
islower(c)   // 0 (false)  — is it lowercase?
isspace(c)   // 0 (false)  — is it whitespace (' ', '\n', '\t')?
ispunct(c)   // 0 (false)  — is it punctuation (!, ., ,)?
isalnum(c)   // true       — is it a letter OR digit?

// Conversion functions:
tolower('G')  // returns 'g'
toupper('g')  // returns 'G'
String Conversion Functions — <stdlib.h>
Convert string representations of numbers to numeric types. Useful when reading command-line arguments (which always arrive as strings).
#include <stdlib.h>

char buf[] = "42";
int    n = atoi(buf);    // "42"  -> 42   (string to int)
double d = atof("3.14"); // "3.14"-> 3.14 (string to double)
long   l = atol("9999"); // "9999"-> 9999 (string to long)
String Functions — <string.h>
#include <string.h>

char s1[50] = "Hello";
char s2[]   = " World";

strlen(s1);            // 5  — length (not counting '\0')
strcpy(s1, "Bye");      // s1 becomes "Bye" (copy entire string)
strncpy(s1, s2, 3);    // copies first 3 chars of s2 into s1
strcat(s1, s2);        // s1 = "Hello World" (append s2 to s1)
strncat(s1, s2, 3);   // append only 3 chars of s2

// strcmp: returns 0 if equal, negative if s1 < s2, positive if s1 > s2
if (strcmp(s1, s2) == 0)
    cout << "Strings are identical";

strstr(s1, "orl");     // returns pointer to first match in s1, or NULL
strtok(s1, " ");       // splits s1 by space, returns first token
getchar() — Character-by-Character Input
#include <stdio.h>
#include <ctype.h>

char c;
int  lc = 0, uc = 0, digits = 0;

cout << "Type something, press Enter: ";
while ((c = getchar()) != '\n')  // read until Enter key
{
    if      (islower(c)) lc++;
    else if (isupper(c)) uc++;
    else if (isdigit(c)) digits++;
}
cout << "Lower: " << lc << "  Upper: " << uc << "  Digits: " << digits;
LEC 18

File Handling — <fstream.h>

Why Files?
Computer memory (RAM) is volatile — all data disappears when the power is off. Files on disk provide permanent storage, allowing data to be saved and reused across program runs (e.g. a payroll system that saves employee data).
File Stream Types
ifstream — Input: read from a file.
ofstream — Output: write to a file.
fstream — Both read and write. 
#include <fstream.h>

ifstream inFile;          // handle for reading
ofstream outFile;         // handle for writing
Basic File Handling — Open, Use, Close
#include <iostream.h>
#include <fstream.h>
#include <stdlib.h>    // for exit()

main()
{
    ifstream inFile;
    char name[50], sal[10];

    inFile.open("employees.txt");   // open file for reading

    if (!inFile)                       // always check if opened OK
    {
        cout << "Error: cannot open file";
        exit(1);                       // stop the program
    }

    while (!inFile.eof())             // loop until end-of-file
    {
        inFile >> name >> sal;         // read word by word
        cout << name << "\t" << sal << "\n";
    }

    inFile.close();                    // always close when done
}
File Opening Modes
// Open for reading (default for ifstream):
inFile.open("data.txt", ios::in);

// Open for writing — creates new or empties existing file:
outFile.open("out.txt", ios::out);

// Append mode — adds to end, preserves existing content:
outFile.open("log.txt", ios::app);

// Open and position at end, can write anywhere (ate mode):
outFile.open("data.txt", ios::ate);
Writing to a File
ofstream outFile;
outFile.open("result.txt", ios::out);

if (!outFile) { cout << "Cannot create file"; exit(1); }

outFile << "Name"   << "\t" << "Salary" << "\n";
outFile << "Aamir"  << "\t" << 14000   << "\n";
outFile << "Amara"  << "\t" << 17000   << "\n";

outFile.close();
get(), put() & getline()
// get() — reads ONE character at a time (includes '\n')
char ch;
while ((ch = inFile.get()) != EOF)
    outFile.put(ch);       // put() writes one char — perfect file copy

// getline() — reads entire line (faster than char-by-char)
char line[200];
while (!inFile.eof())
{
    inFile.getline(line, 200);   // reads up to 199 chars + '\0'
    cout << line << "\n";
}
File + strtok() — Parsing Lines
// Input file line: "Aamir 12000"
// Goal: extract name and salary separately
#include <string.h>
#include <stdlib.h>

char line[100];
int  totalSalary = 0;

while (!inFile.eof())
{
    inFile.getline(line, 100);

    char *token = strtok(line, " ");   // first token = name
    token        = strtok(NULL, " ");   // second token = salary string

    totalSalary += atoi(token);          // convert salary string to int
}
cout << "Total salaries: " << totalSalary;
